# 인사이트 서재

폴더의 인사이트 Markdown과 참고 PDF를 한곳에서 읽는 개인용 정적 웹사이트입니다.

## 시작하기 (처음 받았을 때)

```sh
git clone https://github.com/inwoo-jang/insight-library.git
cd insight-library
```

- **Mac:** `서재-열기.command` 를 더블클릭한다 (터미널이면 `./서재-열기.command`). 처음 한 번은 필요한 패키지를 설치하느라 조금 걸린다.
- **Windows:** `서재-열기.bat` 을 더블클릭한다. Python 3 가 설치되어 있어야 한다.
- 브라우저가 `http://127.0.0.1:8005` 으로 열린다. 창(터미널)을 닫으면 서버도 꺼진다.
- **AI 초안:** 이 컴퓨터에 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 또는 Codex CLI 가 설치·로그인되어 있으면 상단 **마이페이지**에서 골라 켠다. 없으면 + 로 추가할 때 빈 뼈대만 만든다.
- 최신 코드·노트 받기: `git pull`. 내가 추가·편집한 노트는 내 컴퓨터에만 남는다(원래 저장소에 올리려면 저장소 권한이 필요하다).

## 폴더 구조

```
notes/        인사이트 노트(.md)와 원문 PDF
companies/    산업·기업 AX 기업 노트 (_템플릿.md 참고)
web/          화면(template·styles·app.js), catalog.json, covers/, sources.json, rules.md, templates.md
scripts/      build.py(index.html 생성) · serve.py(로컬 서버: 추가·AI 초안·편집) · publish.sh(GitHub Pages 배포)
원본/          옛 자료 보관 — git 에 올리지 않음
```

## 열기

`index.html`을 브라우저로 열면 됩니다. 서버와 인터넷 연결 없이 목록·검색·본문 읽기가 동작합니다. 외부 출처와 원문 이미지 링크는 인터넷 연결이 필요합니다. 원본 PDF와 Markdown, `web` 폴더를 함께 보관하세요.

로컬 서버로 보고 싶다면 이 폴더에서 실행합니다.

```sh
python3 -m http.server 8005 --bind 127.0.0.1
```

브라우저에서 `http://localhost:8005`을 엽니다.

## 할 수 있는 것

- 제목·본문·태그·출처를 함께 검색
- 주제 필터, 기준일(원문 발행일, 없으면 정리일) 기준 최신순·오래된순과 가나다순 정렬
- 글 전체 읽기, 목차 이동, 관련 인사이트 이동
- 원문·참고 링크 바로가기와 출처 모음
- 책갈피 저장, 원본 Markdown 내려받기, PDF 열기
- 모바일 화면 지원, 키보드 탐색 (`/` 검색, `Esc` 본문 닫기)

책갈피는 현재 브라우저의 저장소에 보관됩니다. 다른 브라우저나 기기로 동기화되지는 않습니다. 저장소가 차단된 경우 현재 창에서만 유지하며 화면에서 안내합니다.

## 새 소식 추가 (+)

상단 오른쪽 **+** 버튼으로 플랫폼(최신 이슈 · 산업·기업 AX 사례 · 국내 서비스 개발 · AI 개발·에이전트·추론 · 논문·모델링 · 모델 비교·코드 발견, 29곳)을 골라 아직 서재에 없는 글을 불러오고, 검색·더보기로 이전 글까지 찾아 추가합니다. 목록을 불러올 수 없는 사이트(↗ 표시)는 사이트를 열어 읽고 주소를 붙여넣어 추가합니다. 플랫폼 목록과 설명은 `web/sources.json`, 추천 확인 루틴은 `web/routine.json`.

- 이 기능은 로컬 서버가 필요합니다. **`서재-열기.command`** 를 더블클릭하면 서버를 켜고 브라우저로 엽니다. (터미널: `.venv/bin/python scripts/serve.py`)
- VS Code Live Server 등 다른 주소로 열어 둔 경우에도, 서버가 켜져 있으면 + 버튼이 `127.0.0.1:8005` 에 연결됩니다.
- 추가하면 `YYMMDD_<출처>-<제목>.md` 노트와 미리보기 이미지가 생기고, `web/catalog.json` 과 `index.html` 이 갱신됩니다. 마이페이지에서 AI 초안을 켜 두면 템플릿대로 본문까지 써 주고, 꺼 두면 빈 칸이 있는 뼈대만 만듭니다. 제목의 `[리포트 다운로드]`·`| 9월 MI리포트` 같은 꼬리표는 자동으로 뺍니다.
- 추적할 사이트는 `web/sources.json` 에 있습니다. SK AX 는 목록을 브라우저에서만 불러와서, 서재에 있는 가장 최근 글 번호 다음부터 차례로 확인합니다(30초 정도 걸림). KT Cloud 는 RSS 를 읽습니다.

## 노트 템플릿 · AI 초안 · 편집

- **편집 규칙:** `web/rules.md` — 사실만 쓰기, 한 글 = 한 노트(종합편 없음), 제목·출처·날짜 규칙 등. AI 초안도 이 파일을 읽는다.
- **템플릿:** `web/templates.md`. 모든 노트는 `한 문장 인사이트 → 원문 요약 → 유형별 가운데 섹션 → 읽고 얻은 관점 → 적용 질문 → 읽을 때 주의할 점(맨 아래 작은 글씨)` 순서다. 유형(사례 · 정책·규제 · 기술·연구 · 전략·트렌드 · 동료 공유)마다 한 문장 인사이트의 문형과 가운데 섹션이 다르다. 이 파일을 고치면 다음 AI 초안부터 반영된다.
- **AI 초안:** 상단 **마이페이지**에서 Claude Code 또는 Codex CLI 를 고른다(모델은 선택). 켜 두면 **+** 로 추가할 때 원문을 읽고 템플릿대로 제목·카드 요약·본문을 쓴다. 이미 있는 노트는 본문 위 **AI로 다시 쓰기**로 원문에서 새로 쓴다(직접 고친 내용은 덮어쓴다).
- **편집:** 노트 위 **편집** 버튼을 누르면 제목과 섹션(부제목 · 세부 내용)을 화면 그대로 고친다. 굵게·얇게·하이라이트·불릿을 도구 막대로 적용하고, 섹션을 추가·삭제·이동할 수 있다. 저장하면 Markdown 으로 되돌려 쓰고 화면을 다시 만든다.
- 세 기능 모두 로컬 서버(`서재-열기.command`)가 켜져 있을 때 보인다. AI 초안은 이 컴퓨터의 CLI 로그인을 그대로 쓴다.

## 산업·기업별 AX

상단의 **산업·기업 AX** 탭에서 지원 회사 리서치를 산업별로 봅니다. 회사 카드에는 지원 직무, 한 줄 요약, 마감일(D-day, 7일 이내는 강조)이 보이고, 같은 산업의 인사이트(`catalog.json` 의 `industry`)가 함께 묶입니다.

- 회사 한 곳 = `companies/<회사id>.md` 한 파일. `companies/_템플릿.md` 를 복사해 채운다.
- 머리의 `> 산업:` `> 지원 직무:` `> 마감:` `> 기준일:` 줄과 `**한 줄 요약:**` 문장을 화면이 읽는다.
- `companies/_비교.md` 는 회사 비교표로, 탭 아래 ‘회사 한눈에 비교’에 표시된다.
- 파일을 추가·수정한 뒤 아래 빌드 명령을 다시 실행한다.

## 인사이트 추가·수정

1. `notes/` 폴더에 `.md` 파일을 추가합니다. 첫 줄은 `# 제목`, 정리 날짜는 `> 정리일: YYYY-MM-DD`로 적으면 인식합니다.
2. `web/catalog.json`에 파일명 기준으로 카드 제목·요약·주제·태그 등을 넣습니다. 등록하지 않아도 기본 카드로 포함됩니다.
   - `cover`: 미리보기 이미지 경로(`web/covers/…`). 시리즈 종합 글은 `"collage"` 로 두면 시리즈 글 이미지를 모아 보여줍니다.
   - `series` / `seriesOrder`: 여러 글로 나눈 묶음(예: KT Cloud News). 0 이 종합 글.
   - `industry`: 산업·기업 AX 탭에서 이 글을 묶을 산업.
3. 다음 명령으로 화면 데이터를 갱신합니다. 기존 Markdown은 변경하지 않습니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/build.py
```

최초 설치 후에는 마지막 빌드 명령만 실행하면 됩니다. 출력은 루트의 `index.html`입니다. 원본 Markdown 본문을 포함하므로 파일 수정 후에는 재빌드해야 합니다. 원문 링크는 문서 안의 링크에서 자동 추출하며 이미지 URL은 출처 목록에서 제외합니다.

## 자료 기준

기존 인사이트 6편과 KT Cloud 정리 1편, 참고 PDF 1개를 포함합니다. KT Cloud 정리는 2026-09-28에 확인한 주요 글 5편을 대상으로 하며, 기사 발행일은 2025년입니다. 기존 메모는 재검증하거나 내용을 수정하지 않고 옮겼습니다. 정리일이 없는 커피챗 메모는 날짜를 추정하지 않습니다. 외부 링크가 없는 메모에는 원문 링크를 만들어 넣지 않습니다.

`web/template.html`, `web/styles.css`, `web/app.js`가 화면을 구성하고, `scripts/build.py`가 Markdown 본문과 목록을 `index.html`에 포함합니다. 런타임 라이브러리나 외부 CDN은 사용하지 않습니다. 로컬 용도로 만들었으며 외부에 배포하지 않았습니다.

